Sync, backup & offline

Progress for all games is saved together.

Cloud sync

Saves your progress to a private GitHub Gist and keeps every connected device up to date.

  1. Create a GitHub token. Only the gist box should be checked (it's pre-checked). Pick an expiration you're happy with, or No expiration.
  2. Click Generate token, copy it, and paste it below. Do this once on each device.

The token stays in this browser and is only sent to GitHub. It can only read and write your gists.

This device is connected. Changes sync a few seconds after you make them, and again whenever you come back to the page.

Offline

The guide saves itself on this device so it opens without internet. Maps are saved as you view them.

Backup code

Copy your progress as a code or a link. Opening the link, or importing the code, on another device loads it there.
